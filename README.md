## FAQ

### Is VideoPatch safe to use on my computer?

VideoPatch is designed as a standalone Windows application. As with any third-party tool, we recommend running it in a secure environment and scanning it with anticomponent software.

### Which versions of the video editors are supported?

VideoPatch is regularly updated to support the latest stable releases of CapCut, DaVinci Resolve, Filmora, VideoPad, HitFilm, and Movavi for Windows.

### Do I need an internet connection to apply the patch?

The core patching process is offline. However, an internet connection might be required for the video editor's initial login or to download any specific patch modules on first run.

### Will this affect my existing projects?

VideoPatch modifies the application's feature set, not your project files. Existing projects will open normally but will now have access to premium features.

### How do I uninstall VideoPatch or revert changes?

Most video editors have a repair function in their installer that can reset the application. You can also contact our support for a specific cleanup tool.

### Does it work on both 32-bit and 64-bit Windows?

VideoPatch is built primarily for 64-bit Windows 10 and Windows 11. 32-bit systems are not officially supported.

### Are the AI features in my editor fully unlocked?

VideoPatch activates the access pathway to AI tools. Performance may depend on your system's hardware (GPU, RAM) and the editor's specific implementation.

### Where can I report bugs or request support?

Please open an issue on the GitHub repository page, providing your Windows version, editor version, and a detailed description of the problem.
